Run a JavaScript program against the current web page to do repetitive multi-step work in one call: read many list items, page through results, fill several fields. Not for a single action: use web_tap/web_type_text for that. code is the body of an async function; return a JSON-serialisable value. The script has no DOM: document, window, location, fetch and every other browser global are undefined; only plain JavaScript (Math, JSON, Array, …) and `qavi` are there, and everything qavi returns is plain data (always await): qavi.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}; qavi.read({maxChars, offset}) → page text chunk {text, nextOffset}; qavi.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}; qavi.query(cssSelector, opts) → first item or null (fields ['count'] → number); qavi.text(cssSelector) → visible text (password-like values read as ***); qavi.tap(ref); qavi.type(ref, text, {enter}); qavi.scroll('down'|'up'|'left'|'right', {amount}); qavi.navigate(url); qavi.wait(ms) or qavi.wait({text, timeoutMs}) → true/false; qavi.log(...). tap/type use refs from the latest qavi.snapshot() in the script. Every action runs through the same execution and recording path as a normal call, including send, post, order, delete and pay. A failed qavi call throws an Error whose message starts with the error code. Limits: {{max_actions}} actions, {{max_reads}} reads, {{max_seconds}} s. A navigation that loads a new page ends the script (endedBy=navigation). Returns result (JSON), logs, and actions with each outcome. Call web_observe before acting after it: the page may have changed.
